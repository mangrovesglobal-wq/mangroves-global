# Mangroves Global — Website Project

Mangroves Global Trading FZ LLC — corporate website with three business divisions:

- Trading (Foodstuff & General Trading)
- Logistics (Logistics & Supply Chain)
- Creative (Advertising, Digital Marketing & Creative Services)

## Structure

- `frontend/` — Next.js website
- `backend/` — Laravel API and CMS
- `docs/` — project notes and reference files

## Brand reference

- Colors: `#f2f6f5`, `#dde7e4`, `#3a5951`, `#22332e`, `#141f1c` (mangrove palette), `#d5ad75` (gold accent)
- Fonts: Plus Jakarta Sans (body), Poppins (headings)
